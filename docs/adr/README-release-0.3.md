# Release 0.3 ADR set

Release 0.3 is governed by these accepted decisions:

- ADR-022 - Identity, Tenant/Merchant, authorization, BFF, and sandbox credentials.
- ADR-023 - Full Reversal, Provider, Payment Attempt association, exact accounting, replay, and atomic completion.
- ADR-024 - Immutable Reconciliation, stable settlement instructions, current-run locking, and narrow corrections.
- ADR-025 - Acyclic module graph and closed Release 0.3 messaging catalogue.
- ADR-026 - Manual Payment retry convergence and secure sandbox merchant webhooks.

Retrospective repository records restore accepted decisions from Technical v1.0:

- ADR-007 - Keycloak authentication.
- ADR-008 - Shared-database tenancy with optional RLS.
- ADR-010 - Reconciliation extraction only after stabilization.
- ADR-014 - Compensating transactions instead of Ledger mutation.

These records do not replace Product Definition v1.7 or Technical Specification v1.7. They explain material decisions and review conditions.

- [ADR-027](ADR-027-define-release-0.3-provider-scenario-health-and-operational-projections.md) - Provider scenario pinning, product health, lifecycle projections, notifications, and SSE.
